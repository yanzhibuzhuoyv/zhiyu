# 知语 0.2.12 手机反馈修复

本轮对应用户反馈 11–24，以及再次强调的“必须主动联系”。手机独立运行，聊天仍由用户所选公司的 API Key 调用；不依赖电脑或 USB。旧版、旧测试回执与旧后端工作区保留。

## 主动联系

修复了三个实际阻断：页面销毁时初次授权设置可能尚未保存；恢复调度时覆盖真实到期时间；成功重新登录后仍保留之前连接错误的六小时退避。普通恢复现在保留真实记录，只有实际验证成功才解除连接错误退避；用户要求暂停、人格间隔和每日上限仍然有效。

首次安静间隔从真实最后互动计算：焦虑 5 分钟、活泼 10 分钟、温暖 15 分钟、温柔/自定义 20 分钟、沉稳 60 分钟、疏离 120 分钟。首次授权 30 秒后可检查是否到期；这不是承诺 30 秒就发消息。后续频率继续受固定人格、未回复次数和每日上限影响，不设统一夜间禁发时段。

`ProactiveEndToEndNativeTest` 实际经过 Controller 授权保存、同 Worker 的 due/服务入口、Repository、SQLite 原文和 Android `NotificationManager.activeNotifications`，只替换远端 HTTP 返回为合成回复。另测前台不主动生成。该验证证明应用链路可以生成并通知，不等于真实云 Key、红米省电策略或整夜到达率已经验证。

安装后允许系统通知；现有日记/关心权限页会显示后台和电池限制，并打开标准系统设置。按 Home 后由 WorkManager 执行，系统省电和网络可延迟。系统“强行停止”后需要重新打开应用；没有后台开麦或隐蔽保活服务。详见 [后台报告](BACKGROUND_CONTACT_2026-10-16.md)。

## 聊天、图片与语音

- 回复可以显示为独立分段气泡，按固定性格调整长短，允许“嗯”“好啊”等短答，去掉固定三句配额。保存和复制仍是完整原文；没有把拆开的视觉片段当新记忆。
- 文字、图片和语音允许连续提交，最多 32 条，按顺序处理。每条保留自己的内容、附件和连接快照；已落库但没有得到回答的原话不会自动重复提交。失败保留状态，较新文字和照片不被旧请求清空。尚未提交的队列在 ViewModel 内，不承诺进程被杀后恢复。
- 可以录制最长 60 秒的实际语音，查看转写、试听、发送和取消；发送的是持久 WAV 与对应原文。恋人可以发送本地合成语音，接收到语音或明确索要语音时优先语音回复，其余按性格低频决定。合成失败保留文字。音频有 SHA、原文和归属校验、容量限制，不删除已发送语音来腾空间。
- 174 个实际音色按官方说话人元数据分为 138 女声、36 男声；保留音高、语速、音量调整与试听。没有重排旧 speaker ID，也不是任意声音克隆。
- 上传当前 OC 的原图时可通过同 SHA 确认“这是自己的设定”；其他图片给支持原生视觉的模型同时提供独立的当前 OC 参考。无法比较时保留自然不确定，不编造识别成功。可选 OC 资料损坏不阻断普通照片发送。
- 移除“图片与表情包”“候选照片”导航；取消新的表情导入、选择和默认打包。安全迁移保留历史已发送附件、共享图片及未知或损坏记录，保留 OC 自拍、生活照和后台候选功能。

语音发送、转写和播放使用本地模型；麦克风只在用户明确录音或接通通话后开启。此次录音合同注入真实 PCM 并验证实际 WAV，未冒称物理麦克风实测。详见 [联系与语音审查](CONTACT_VOICE_REVIEW_2026-10-16.md) 和 [UI 审查](DEVICE_UI_REVIEW_2026-10-16.md)。

## 自拍与视频人物

自拍备库提供三个持久准备位置，消费一张后补充对应位置。索要时强制附上当前 OC、当前轨迹、实际审核通过的新自拍，不再依赖模型恰好输出媒体标记；用户说自己要拍自拍、发自己的自拍或问教程时不会误消耗库存。原 OC 参考图、已消费相同像素和过时/未审图不能当新自拍。没有可用图时自然说明暂未准备好。

生成仍需要独立图像服务 Key，实际双像素审图需要具备视觉能力的审核模型；纯文字 API 不会被假装成识图模型。本轮没有新的收费生图或真实云审图验收，库存测试使用隔离的合成审核素材。消费标记先于聊天保存落地；保存失败可能少一次库存机会，不会二发同张图。详见 [自拍备库](SELFIE_BANK_2026-10-16.md)。

仅导入图片、没有手工角色包时，可靠的单正脸会建立局部临时动作。背景和实际脸部轮廓固定，内部有可见呼吸/轻偏转；多人、侧脸、线稿或小脸回到原图，并提供“标注人物，让 TA 动起来”。已保存手工角色包优先，可以调整已确认部位。临时检测没有准确眼嘴地标，未宣称完整自动 Cubism 或所有 OC 自动口型。详见 [人物和音色](AVATAR_VOICE_UI_2026-10-16.md)。

## 通话

通话输入、输出、中断前缀均不再进入文字聊天时间线，也不占用文字发送队列；原话仍独立保存在原记忆链。保留持续监听、播放重叠、插话取消及 DeepSeek SSE 首句合成。静音端点从 800ms 减到 480ms，视频默认扬声器优先于听筒，耳机优先。

只有不超过 16 字的明确问候/应答白名单使用近期原文快路；事实和旧事问题继续走原 RAG。通话近期正文预算为 12000 字符。原向量、排序和逐条原文保留没有替换或融合。十万向量下已有的约 20 秒检索问题仍是后续优化项，云模型首音、物理回声、蓝牙和红米实时听感尚无本轮实机结论。
