# 在手机上把 OC 图片做成动态形象

适用于知语 0.2.15。这里的“动态形象”是单张原图的局部动画：保留原背景，可以做轻微头部动作、眨眼、口型和附件摆动。需要给对应部位设置活动区域；只标眼口时不会自动拥有头部/身体动作。图片里没有画出的背面、被遮住的眼嘴不会凭空补出来。

## 先完成最小的一版

1. 聊天页右上角“更多设置”→“恋人外观”，导入你的 OC 图片。确认页面里已经显示这张图，再点“完成”。先选脸较大、眼口清晰的一张图比较容易；背景可以保留。
2. 再打开“更多设置”→“动态形象”。上半屏应该显示刚才的原图。如果提示先导入图片，返回外观页确认导入完成，不要停留在尚未确认的候选图片。
3. 点“左眼”，在图上从眼睛一角拖到另一角，框住**图上左侧**那只眼睛；点“右眼”后同样框另一只。先按图上的左右操作，动画预览不对可以重新框。
4. 点“嘴巴”，拖出一个紧贴嘴部的小矩形。不要把下巴、头发或整张脸一起框进去。若图片是闭嘴，张嘴效果只能作小幅局部变形，不会自动画出口腔。
5. 点“头部”，在脸/头部中心点一下；点“颈部”，在头与脖子的连接处点一下。这里是点选，不是拖矩形。
6. 保留能看清的“左眼动作”“右眼动作”“口型”勾选。侧脸、遮脸或没有画出的部位直接取消对应勾选；嘴被麦克风或手挡住时，关闭口型，不要把道具框成嘴。
7. 点“补充头部微动”（通话页提示“补充头部动作”也会进入这里），给已有头颈/眼睛位置追加一个可撤销的头部建议层。建议不是自动识别保证：用原图对照检查轮廓，避开背景、麦克风、手和固定道具；需要时重画轮廓或降低“随动幅度”。如果把眼睛擦出“人物活动范围”，即使框对眼也不会动，要用“画保留”恢复真正需要活动的眼部。不要删除原背景。
8. 点“动画预览”，当前**未保存的标注也能预览**；观察至少 6 秒，检查眨眼和局部微动。没有头身活动层的版本只有间歇眨眼和语音口型，不能把静止等待当成还在生成。满意后点“返回标注”，再点“保存并用于通话”，等“形象已保存，下次通话会使用这个角色”。预览和正式保存是两件事；这一步是本机生成角色包，不是云端生图。
9. 关闭编辑页，打开视频/通话。已保存且与当前原图对应的角色包会优先使用。开始语音后，只有已启用并正确框好的嘴部才会随声音活动。

不要一开始追求大幅转头。先确认眼睛只在眼部活动、嘴只在嘴部活动、背景不跟着飘，再逐项加细节。

## 再加头发、翅膀或武器

1. 返回“动态形象”，点“添加头发／附件”，给新层起名。
2. 选“头发”或“翼／武器／道具”，点“点选轮廓”，沿目标边缘依次点出至少三个点，再点“完成轮廓”。每只翼或各自运动的物件可以单独建层，不需要符合普通人体数量。
3. 用“画保留”和“擦除”细修；画笔只调整这个活动区域，原图仍保留。误操作可以“撤销”。
4. 先把“随动幅度”调低，保存后预览。幅度过大可能露出单图本来没有的区域，不是扩图成功。
5. “移前一层／移后一层”调整遮挡。武器被手握住时宜保持很小幅度，先避免握持处漂移。

“人物活动范围”用于限制哪些像素可以活动。背景被带动时，选择它，用“擦除”排除背景区域，再保存验证。没有必要把所有背景删掉或重新抠图。

## 没动或不对时这样定位

| 现象 | 检查 |
| --- | --- |
| 原图有，但一直静止 | 先看是否提示“只有眨眼和口型”；若是，补充头部动作并检查活动范围。再确认正式保存、当前原图对应；只有眼口时可能要等几秒才有眨眼。 |
| 眼睛或嘴的位置不对 | 回到对应按钮，重新拖框；框尽量紧，只覆盖可见部位。 |
| 侧脸眨眼很怪 | 关闭被挡住/不存在的那只眼睛动作，不要把侧脸当正脸硬框两只眼。 |
| 线稿没有自动动起来 | 当前自动正脸检测对线稿不可靠，按上面的手工标注做；自动失败不代表图片还在生成。 |
| 换图后旧角色没了 | 角色包绑定原图；换了 OC 图片要为新图重新标注，避免把旧眼嘴套到新脸上。 |
| 点击动画预览看到旧效果 | 0.2.15 会用当前标注重新生成预览；先点“返回标注”修改，再点“动画预览”。预览满意后仍须正式保存才能用于通话。 |
| 开了视频没口型 | 确认已勾选“口型”、嘴部框正确，并确实有语音播放；静止画面不会凭空模拟讲话。 |
| 提示失败 | 保留具体提示，尝试只做眼口与头颈的最小版本；有未完成的附件轮廓时先完成或删除该层。 |

关闭会暂存未保存标注，撤销记录只保留当前编辑期间；正式保存后可“导出角色包”备份。先试这版最小流程，仍不成功时可以接 USB 定位具体保存或渲染问题，不需要清除 Key、绑定或聊天。
