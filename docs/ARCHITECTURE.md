# 知语首版方案

原生 Android（Kotlin / Compose）通过 REST 调用 FastAPI。服务端持久化 SQLite 会话和知识库，API Key 仅用于向选定厂商鉴权，登录后发放独立随机会话令牌。Key 在服务器进程内存短期保存，重启后需重新验证；设备端使用 Android Keystore 加密保存，退出时清除。

## 实现顺序

1. 研究并复用 `../rag-system` 中文分块与检索，不修改原工程、原索引或 `.env`。
2. 编写隔离、鉴权、错误映射和聊天持久化测试，再实现后端。
3. 统一国内厂商 OpenAI 兼容协议，模型由用户选择或填写；豆包允许填写接入点 ID。
4. 实现原生连接、会话、聊天、知识库和设置界面，产出 debug APK。
5. 后端测试、Android 构建与单元测试、独立代码审查；修复高风险问题。

## 范围

- API Key 直接登录，不额外创建用户名、密码或短信账号。
- 每个服务商 + Key 是独立数据身份，相同 Key 再次登录可读取原会话。
- 会话创建、历史、删除、知识库开关；文档上传、删除、检索、来源展示。
- txt / md / pdf / docx，上传上限 5 MiB。扫描 PDF 的 OCR 不属于首版。
- 默认中文 BM25 可离线运行，另提供本地 BGE 语义检索配置。模式对外明确显示。
- 云端 API 与真机联网需要用户自己的有效 Key 和可达后端；本地演示必须显式开启并标明。

## 安全边界

固定服务商 HTTPS 地址，无任意上游代理地址；不跟随重定向；上游错误脱敏。每次资源访问校验 Key 身份，文档引用是低信任文本而不是系统指令。服务器部署需 HTTPS，调试版支持本地 HTTP 联调。真实云端费用和配额由 Key 对应的厂商管理。
