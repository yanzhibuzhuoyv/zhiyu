# 知语 0.2.4：照片、主动联系、音色与学生模型接线

本轮按用户要求在电脑模拟器验证；没有连接真实手机、读取真实 Key／聊天，或发起付费 API 请求。既有万轮、五千万和红米约 32 分钟生图实验没有重跑。

## 学生版在 APK 中的真实接线

- 菜单“本机照片”通过系统文件夹选择器导入模型，64 KiB 流式复制、精确大小／SHA、私有 staging、fsync、再次校验和原子发布；取消保留活动包。
- 模型清单固定 SHA `9232afcbed6d188a9bdc58c0b8841b35bb12773aaee9fc745dc8027641c656e6`，四项权重共 **5,290,983,724 字节**。只把受信清单放入 APK，未把权重或测试 CP 打包进去。
- JNI 为真实原生实现：student/tokenizer＋六层 adapter → DiT 8 步采样检查点 → 单独 VAE 解码。arm64 与 x86_64 双库独立构建、隐藏 GGML 符号，固定 fork／上游身份；构建再次核查四个源 DSO SHA。
- 同 App UID、非 exported 的 `:qwen_text`／`:qwen_image` 进程逐阶段运行。HELLO 核验实际 JNI 身份，STOP 后确认真实 Binder death 才进入下一阶段；未确认停止是可延期状态，不消耗某张图失败预算。
- 前台可取消长任务、持久阶段／CP。开始及运行中用 App API 检查温度、thermal、内存和磁盘；未知状态不假装安全。全局 CPU 低占用优先；下一天缺图只绕过闲置偏好，不能绕过资源硬门。
- 每条 job 原子保存，跨进程 FileChannel 锁保护 `AtomicFile.openRead` 的 .bak 恢复；一个坏记录保留并跳过，不重新创建可能已收费的描述请求，不阻塞其他库存。
- 当前用户 Key 生成英文背景描述、看实际图片复审；一次背景明确否决可修正重绘一次。未知付费结果不自动重复调用；保存每次解码图与复现参数。
- 原 OC 固定主体合成后再审图，区别背景、人物合成、第一人称可见片段；缓存审批绑定 PNG SHA、参考 SHA、用途、job 与实际轨迹／外观版本。背景不要求 OC 出镜，POV 不要求完整人物出镜。
- 已装学生包的库存路由不自动回退 Agnes／Canvas，不会把 pending、unknown、拒绝或占位画面宣称为生成成功。

学生版目前只验收为 **背景 T2I**。人物来自原参考主体合成；不能由这些证据宣称任意新动作、参考图重绘、自动扩全身、完整 Cubism／全双工已经实现。参考形象生成服务仍保留独立入口，未冒称 Agnes 的全部功能都已替代。

## 保留的具体限制

- 本轮没有新手机或用户 Key 云端视觉实测；传像素正确不等于与 DeepSeek App 识图质量相同。完整 APK 内新 prompt → 整图尚未物理执行，原约 32 分钟手机实验是独立研究链。需要后续有手机时验收新 App UID 的真实完整任务／中断恢复。
- CPU 生图仍慢，使用预备图库而非即时生成；后台任务受 Android/OEM/Doze/配额调度，通知和零点刷新不承诺精确到秒。当前主动联系在 App 前台可见时跳过生成。
- 同 SHA 私有模型目录损坏后，“重新校验”暂不能直接替换修复该目录；原包保留，不自动删除 5 GB 数据。这是明确 P2 后续项。
- 可用视觉能力来自绑定的模型。没有视觉能力或无法确定的复审不会被 OCR 冒充或批准。
- 本轮原始 RAG 算法、逐句原文与既有长测结果未改。2D/3D 建模维持取消状态，全双工不在本轮范围。

开发证据均位于 `artifacts/`；权重、APK、临时凭据、私有交接不提交 Git。旧后端未提交内容原样保留。
