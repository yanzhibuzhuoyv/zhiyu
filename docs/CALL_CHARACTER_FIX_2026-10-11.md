# 0.2.3：视频形象、照片发送与取消建模

2026-10-11。用户反馈导入／生成图片后视频页仍显示未设定，照片点击发送没有发出；本轮随后追加取消 2D／3D 建模。新版本为 0.2.3 / versionCode 9，沿用现有签名和手机本地存储。电脑模拟器用于验证，不等于本轮已在红米 Turbo 3 复现所有现象。

## 已修复的链路

视频页此前只读取角色编辑器生成的制作档案。导入、确认抠图、采用生成候选会更新外观中的参考图片，却不创建这份档案，因此明明有图片仍显示未设定。现在以当前已确认图片为依据；图片 ID、SHA、外观版本完整匹配的照片动画档案可以复用，否则直接显示当前图片。身份保持稳定，换图和切换聊天会刷新，图片加载仍验证 SHA，取消时释放位图。只保存描述、没有确认图片时仍不虚构形象。

保存性别、发型或外观模式描述曾清空参考图。现在除显式移除外观外保留图片；版本继续递增，使旧抠图预览和旧后台任务失效。照片动画参数若属于旧版本，不借给新版图片；已确认原图仍能显示，重新保存局部动画后恢复相应参数。

照片发送此前要等待 OCR／独立识图完成才提交用户原话，界面又要等 AI 回复完整完成才清草稿和显示已提交消息。识图或回复失败时，已保存图片还可能从当前列表消失，重发同一附件会重复写原话。现在先验证原图及派生文件、保存用户消息并通知界面，立即显示照片、清除已提交草稿；再继续 OCR／独立识图和 AI 回复。回复失败保留图片并显示真实错误，不补造回答。

重试同一精确附件 ID 时，只有同 owner、聊天、原文字、完整附件元数据且仍为末条未回复消息才复用原消息 ID／时间；已回复或有后续消息时不重复调用。相同像素重新选择产生新附件 ID，仍是一次合法的新发送。空文字照片不改成用户亲口文字，RAG 的原文与检索规则保持。

无法仅凭“点击后没发出”证明手机当时具体停在识图、服务商请求还是其他步骤。本轮确认并修复上述可复现的提交／界面／重试缺陷，没有将未连接的手机或未调用的真实服务商写成已验证。

## 取消 2D／3D 建模

去除部件／捏脸／三维相机编辑器与选择入口，制作控制器和图片发布入口拒绝新 2D／3D 模型；预览不再启动 GLSurfaceView。保留导入、生成、抠图笔刷及照片眼口／呼吸等局部动画编辑。

历史模型档案、已发布 PNG 和待恢复记录保留；视频与每日生活图把它们映射为当前已发布图片，不重新渲染几何，也不把旧身体／部件参数借给照片。后台合成保留原档案 `packageSha`、`ocId`、修订及外观版本校验，不写回临时映射身份。旧 schema 与兼容验证中的几何工具保留，已无产品 UI／制作／生活库存调用。完整自动 Cubism 和全双工没有在本轮完成。
