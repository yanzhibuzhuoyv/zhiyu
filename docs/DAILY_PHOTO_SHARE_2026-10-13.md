# 知语 0.2.6：带图片的主动日常分享

用户要求在轨迹系统上增加日常分享，按性格每天伪随机 0–7 次，并且每次带图片。本轮只扩展 Android 本地版本；原本的单文件离线学生模型包保留，不重新打包权重。

- 分享继承已有通知授权与主动联系的授权状态，不新增用户设置页面。通过已绑定服务商、模型与用户 Key 生成自然配文，后台联网才能完成。

## 分享机制

次数由聊天 ID、北京日期和固定性格生成确定种子，使用加权分布。焦虑、活泼型更容易多分享，成熟、疏离型更容易少分享或当天不分享。用户未回复不会为日常分享重新抽签，也不会突破当天配额；普通主动联系和夜间惊醒仍执行各自原有规则。

首次检查保存当天配额、已选活动、时间窗口和稳定 UUID。重启、重复调度及图片到货不会改次数、改已选活动或重新发送。新生成轨迹含七件候选日常；已保存的旧轨迹保持原文，因此旧轨迹候选少时，实际次数可以少于抽出的上限。

每条围绕实际保存的单一 OC 活动，时间在该活动开始后伪随机延后 3–20 分钟，短活动窗口会缩短延后。最迟在到期后 45 分钟、下一活动开始或午夜时过期，取最早者。凌晨休息不选作新鲜事情，不补发已过时活动。

当日选中活动缺图时，15 分钟后再检查；库存产出图片也会触发独立的短检查。缺图不调用配文模型、不扣除已完成次数、不发送纯文字或表情包。过期之后跳过，继续后面的活动。

固定图片必须符合以下条件：

- 实际本地图库图片，非临时 Canvas 占位图；存在、字节 SHA-256 校验一致。
- 日期、形象版本、轨迹 revision、活动时段均一致，不能用次日图片或其他活动替代。
- 已完成解码的日轨迹库存；学生产图必须通过已有合成与审核流程。旧真实背景库存可以继续参与；普通用户聊天附件不当作日常库存。
- 含人物时，当前 OC 参考图存在且完整；模型生成回来后，形象、轨迹、Key、绑定、性格、时间与图片字节再次检查。
- 同一张图不在当天这段聊天重复分享。图像 SHA 在发送前和 SQLite 提交事务中都检查。

更新 OC 形象时，未发送事件保留原次数、活动、UUID 和时间，只更新视觉与轨迹版本，等新对应图片。已发事件不重复；实际活动若改了，就放弃旧事件，不补抽另一件。

## 配文、聊天与记忆

配文保持已绑定性格，只分享本次 OC 日常的感受，不虚构用户的位置、行程、约定或摄像头观察。不输出查记录、数据库、文件名等工程自述。

绑定模型具有已核实的视觉能力时，收到实际图片像素；没有视觉能力时，只根据已保存事项写感受，不猜图片细节，不偷偷更换服务商或调用 Agnes/OCR。模型产生的可选图片标记不会丢掉固定附件，日历协议也不会执行。

最终一条 `assistant / daily_share` 消息同时保存自然正文和固定图片，进入同一段聊天与原来的逐句原文索引。没有新用户消息、没有新会话，没有改 RAG schema、排序、压缩、三层记忆或引入记忆融合。聊天继续使用已有图片显示和秒级时间戳。

主动联系的统计排除 `daily_share`，避免把恋人分享误当作用户刚刚说话，从而重置普通联系的间隔。

## 持久化与后台接线

独立 SharedPreferences 保存派生计划、完成事件、图片 SHA、随机 worker 请求到稳定事件的映射，以及日常检查结果。只保留当天和前三天的派生调度记录，不删聊天原文或已解码照片。

日常有独立 WorkManager 名称、请求与下一次检查时间，不使用普通联系的每次最多两条额度。通知授权、App 启动恢复、首次轨迹、午夜刷新和库存完成均已接线；前台聊天时不后台发起分享，回来会取消正在生成的后台配文，通知发送前再检查权限和前台状态。

已提交的消息先按稳定 UUID 恢复，重试不再生成另一条消息。旧请求若未提交且活动已经过期，会释放该次 worker 请求，由新请求处理下一个活动，不允许把旧请求编号改绑后续活动。

## 尚未覆盖与已知边界

- 本机消息和通知幂等不等于服务商付费接口幂等。网络结果未知、IO/5xx 等退避重试可能再次调用模型并重复计费；本轮保留原有重试语义，不声称付费 exactly-once。
- Android/OEM 可以延后后台任务。窗口过时跳过，不承诺按秒准时或每天恰好发满配额。本轮没有红米 Turbo 3 的屏幕关闭、省电/自启动、通知点击实机验收。
- 未导入学生模型或没有完成审核的真实库存时，不会用占位图冒充每日照片。学生模型仍是背景生成与原 OC 合成，不能据此宣称人物任意新动作、全身扩图、完整 Live2D 或全双工已完成。
- 损坏的图库 metadata 可能使本次候选选择整体失败；宁可等待或跳过，也不发错误图片。本轮未改全图库损坏隔离策略。
- 手机日期手动向过去调超过三天时，派生计划的四日保留策略可能挤掉当日记录；本轮测试覆盖正常跨日和持久轨迹回退，未保证任意大幅时钟回退。
- 收到 401 后日常检查保留六小时连接退避；重新验证 Key 时，独立日常 due 可能尚未立即重置，已有新图片到货可提前唤醒。明确的连接恢复短检查可后续补充。
- 此前万轮/五千万 Unicode 以及约 32 分钟学生 CPU 研究不重跑。本轮不做额外生图，不改离线模型权重或已有长期测试结论。

本轮之外旧 backend 9 个 tracked 修改、23 个未跟踪文件原样保留，不混入本轮提交。旧安装包、图片和历史失败日志保留。
