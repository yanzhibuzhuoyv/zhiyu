# 原生记忆压力测试总结（2026-10-09）

本轮只执行了两类测试：一万轮本地冒烟测试，以及五千万字符级记忆测试。测试运行在隔离 Android Emulator `zhiyu_local_20261009`（serial `emulator-5582`）中，没有使用 Redmi 真机、电脑反向代理或 Docker 后端。

## 一万轮冒烟测试：通过

日志：`artifacts/native-memory-10000-rounds-r9.log`

- 10,000 轮，20,000 条消息。
- 原文 UTF-8 字节：183,882,659。
- 数据库主文件：234,037,248 bytes；WAL：0；共享内存：32,768 bytes；总存储：234,070,016 bytes（约 223.3 MiB）。
- 重启后完整原文哈希校验：通过。
- 本地记忆召回：8.70 ms。
- 总耗时：113.45 s。
- Provider 调用：0。
- Instrumentation：`OK (1 test)`。

这轮验证了大量长原文逐句保存、重启后仍可读取、不会做记忆融合，以及数据库空间随原文增长的实际表现。

## 五千万 Unicode 字符测试：通过

最终日志：`artifacts/native-fifty-million-resume-r9h.log`

该测试沿用了之前已经写入并通过完整重启校验的 5,000 条消息归档，每条消息严格 10,000 个 Unicode code point，总计 50,000,000 个 Unicode 字符。按确定性测试文本重新计算，其中汉字约 45,911,013 个，占 91.822026%；其余约 4,088,987 个是标点、数字等非汉字字符。因此，原测试的中文有效负载已经接近 4,600 万汉字，但它不是“只含汉字”的口径。

恢复索引从已保存检查点继续，最终结果如下：

- 消息：5,000/5,000。
- Unicode 字符：50,000,000。
- 语义分块：100,000/100,000。
- 已完成语义消息：5,000/5,000。
- 失败消息：0。
- 重启后语义覆盖校验：通过。
- 四组远距离问题均检索到独立原文；检索结果保留多条独立原文，没有融合改写。
- 四次 DeepSeek 官方 HTTPS 调用均通过事实校验和自然表述校验。
- 单次检索耗时约 20.66–21.56 s；单次完整回答约 21.97–22.47 s。
- Instrumentation：`OK (1 test)`。

检索路由中出现了 `semantic_then_lexical` 和 `lexical_fallback`。这说明当前实现会先做语义检索，低于阈值时再走精确词法补漏，且最终仍返回原文消息。

凭据清理证明：`artifacts/native-fifty-million-resume-r9h-credential-proof.json`。该证明记录了来源文件 SHA 未改变、临时 key/model 文件已删除、key 未出现在命令参数中。

## 汉字口径补充验证：已停止，未计入通过项

应用户临时修正的口径，另启动了一个“每条消息严格只含汉字”的版本：5,000 条×10,000 个汉字。它已完成 50,000,000 个汉字的写入与每条消息汉字计数校验，随后在用户要求停止时完成到 152/5,000 条消息、3,072/100,000 个向量分块的语义索引。

这项实验验证了汉字计数口径，但没有完成全量语义索引、重启检索和官方回答，因此不作为通过项，也没有把部分结果混入正式结论。

## 测试过程中修正的测试夹具问题

- 首次恢复测试的消息计数使用了单页读取；由于每条原文约 30 KB，单页受 2 MB 上限限制，导致“原文改变”的假失败。已改成完整游标分页后复测。
- 召回断言原先把多个候选写成“全部必须出现”，与候选语义不符；已改为候选集合命中任一项，独立原文仍保留并逐条验证。
- 官方回答夹具曾直接发送最后 48 条长原文（约 48 万字符），超过当次模型上下文预算；并非发送五千万全文。最终改为使用数据库预算后的近期上下文（默认最多 48,000 字符），并把远距离信息通过 RAG 独立原文提供给模型。

## 边界与解释

- 五千万测试证明的是本地原文持久化、重启一致性、语义索引覆盖和远距离检索；它不是自然聊天质量或长期人格拟真的完整评测。
- 10,000 轮测试是本地存储/召回冒烟测试，不代表网络 Provider 延迟。
- 五千万完整语义索引的最终数据库体积没有用被用户中断的旧快照冒充；旧快照约 607,465,472 bytes，只代表 2,772 条消息已完成语义索引时的现场。
- 本轮没有把图片、通知、日历、定位、Live2D 或语音通话等后续功能混入测试结论。
- 诊断副本 `artifacts/fifty-million-resume-r9c-failed.sqlite3` 以及严格汉字版的隔离现场未被强制删除；精确清理命令被自动审批以 `blocked by policy` 拒绝，未绕过该限制。
