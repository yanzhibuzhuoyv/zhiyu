# 知语 0.2.4 试用

安装桌面的 **知语-0.2.4-手机独立版.apk**，覆盖旧版即可，保留原 Key、绑定、聊天。正常聊天只需要手机联网，无需连接电脑或 USB。

- 聊天菜单 → **声音**：三种快捷音色之外，可输入 **1—174** 选择声线，也能上一种／下一种试听；语速、音高、音量分别调整后保存。
- 重新尝试首次选择照片直接发送，以及大照片导入聊天／恋人形象。发送副本会缩小，原图保留。
- 通知权限保持允许，App 放后台后会按恋人性格主动联系；低频夜间惊醒事件可能出现，并非每晚必发。Android 系统限制可能推迟投递。
- 当天及后两天轨迹会提前准备；次日图片优先。过期仅清理生成中间数据，不删除已解码照片或原人物图片。

## 学生模型

若要启用手机本机背景生成，将以下文件夹里的四个权重文件复制到手机同一文件夹，再打开菜单 **本机照片 → 导入模型文件夹**：

`C:/Users/32202/Desktop/99999/zhiyu/artifacts/model-packs/qwen-edge/`

| 文件 | 用途 |
| --- | --- |
| student-q4_K_M.gguf | 学生文本编码器 |
| adapter.fp32.bin | 条件适配 |
| dit-q4_K.gguf | 图像采样 |
| vae-bf16.safetensors | 图片解码 |

四项共约 **5.29 GB**。手机导入到 App 私有目录时还需约 **5.29 GB＋512 MiB** 可用空间；聊天与语音本身不用等这个模型。完成后由当前 AI Key 生成生活图描述并看图审核，图片在后台提前准备。

这版学生模型负责背景，人物使用固定原 OC 主体合成。暂不具备任意新动作、自动扩全身或完整实时 Live2D。原红米 CPU 研究单图约 32 分钟，不能当作即时生图。

详细测试记录见 [0.2.4 验证](NATIVE_V5_VALIDATION_2026-10-12.md)。
