# 自然表情与 QQ 风格素材

普通日常分享也能收到表情，用户无需先说“发表情包”。主模型在正常回答的同一次调用里，根据已提供的对话上下文和自己的回复语气，从缓存候选中选择一张或不发；不增加第二次同步分类请求，不在聊天时等待生图。

图片请求仍走既有 OC 身份、日轨迹与缓存选择。表情已经移除“用户情绪关键词 + 每 N 轮取模”的旧规则。贴纸中的卡通角色只是表达方式，不被当作恋人的 OC 长相或用户事实。固定性格保持绑定，自调人格仍可以通过自己的描述控制表达。

## 频率与发送范围

频率只限制候选机会，不要求模型凑次数。以当前会话的 AI 消息计算两张贴纸之间的最小序号差：playful/anxious 为 2，gentle/warm 为 4，steady 为 12，distant 为 20。首次也可以自然选择，成熟/疏离提示倾向不发。最近 20 条消息中出现的同一 SHA 不再候选；其他账户和全局数据库序号不影响频率。

当前含“表情包”的请求可放宽间隔，但仍不绕过最近图片去重、owner 或 OC 身份检查，也不会强制发送。后台主动联系使用同样的表情语义选择；普通回复中的表情不依赖通知权限或主动联系开关。主动联系本身仍按原有性格策略和用户开关执行。

模型没有输出有效选择时，仍保留正常文字回答，不凭关键词猜图。空自然正文继续报错，不能只用表情替代回应。

## 内部协议与原文保存

每轮创建随机 nonce 和最多 12 个候选 ID。模型正文保持自然文本，仅末尾独占一行选择 ID 或 `none`。解析器只接受本轮 nonce、单一末行和候选白名单；未知 ID、旧 nonce、多标记及正文中的标记不选图。保留的控制命名空间在保存之前移除，不显示给用户，也不进入聊天原文/RAG。双方自然聊天仍逐条独立保存。

候选说明按 JSON 转义，并明确为低信任素材数据。没有匹配库存时不虚构图片，也不读取其他 owner 的 OC。

## 素材目录更新

运营清单继续使用数组 `{kind,file,metadata}`；每张说明应准确描述画面和适用语气，而不是只写“开心”。正式可分发素材与网上收集的本机预览素材分开保存许可和来源，不能把收集仓库的代码许可套到第三方图片上。

新目录支持可逆停用公共来源。停用的素材退出新候选，历史附件仍可鉴权下载；用户私有素材及照片库不受以下操作影响：

```powershell
python -m app.media_cli --media-dir <外置素材目录> --disable-sticker-source "Microsoft Fluent Emoji"
python -m app.media_cli --media-dir <外置素材目录> <新素材清单.json>
```

旧库在初始化时迁移 `active` 字段，现存素材默认启用。公共来源可由本机运营端通过 `AssetLibrary.set_source_active(label, True)` 恢复，没有面向普通用户的共享图库写入接口。

当前电脑试用批次、实测结果和分发界限见 [表情验证](STICKERS_VALIDATION.md)。
