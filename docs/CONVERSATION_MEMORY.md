# 连续聊天的逐消息 RAG

用户与 AI 每条成功保存的原话都进入聊天索引。最近聊天直接给模型，更早的相关原话按需召回；无需新建话题或上传聊天记录。关闭文档 RAG 不会关闭聊天记忆。

## 原文与索引

`messages.content`是唯一原文来源。`memory_fragments`只存消息序号和原文字符位置；SQLite FTS5的contentless索引只存派生词项，不保存第二份正文。每段最多768字符、重叠128字符，覆盖长消息中间和尾部；召回返回原文子串。

user与assistant消息、来源和索引处于同一事务。上游调用或索引写入失败不保留半轮。已有消息启动时以128条为批次补建，失败批次回滚，重启不重复。删除会话通过外键和触发器同时清理消息、片段和FTS记录。

需要SQLite >=3.43且支持contentless_delete，不兼容时明确报错。Windows SQLite3.49.1、Docker SQLite3.46.1实测可用。词项使用UTF-8十六进制编码防止输入改变MATCH语法；编码不是加密。

## 有界检索与权重

1. 最近最多20个完整轮次、48,000字符直接进入上下文。
2. 提取最多32个中文双字词或英文词，过滤泛化回忆用语。“你记得我吗”不会随机召回经历。
3. FTS在当前身份、会话、近期边界之前检索，先把片段归到完整轮次，再应用最多256个候选配额：192个相关候选与64个较新候选。每个角色读取最佳匹配片段，另一方没命中时取开头原文。
4. 查询词覆盖率与归一化BM25共同排序，默认BM25比例0.20；AI匹配贡献乘0.65，用户原话优先。时间仅提供最大0.05的衰减加分，老事实不因年龄淘汰。分数是排序分，不是事实置信概率。
5. 保留最新相关用户原话，即使没说“更正”；另保护明确更正。较新的AI说法不能充当用户修订。
6. 对最多两个较强用户命中，以保存时间前后12小时查找最多32个用户原轮次。身份、会话、user角色、边界和时间条件都在去重及LIMIT之前。候选包括过去经历的生日/纪念/庆祝，以及与锚点共享时间措辞的第一人称原话，不限制为食物等主题。排除已识别的未来计划、假设和AI自述。
7. 最多补一个附近原轮次，权重为锚点直接相关分的0.65，不能挤掉更强的直接事实、最新用户说明或保护的更正。最终最多4个完整轮次、8条独立原文、6,144字符，按原顺序提供。

共享“昨天”“前天”“那天”等只是检索线索。`created_at`是保存时间，**不是事件发生日期**；相对日期要结合原话保存时间与用户当地日期理解。`reason=nearby_event`、`anchor_ids`描述检索路径，`relation_confirmed=false`表示联系未确认。保存时间相近不证明发生在同一天；“昨天生日”“前天吃饭”仍保留各自原意，不能改成同日事实。

“鸡翅与生日”只是合成测试例子。音乐与心情、海边与流星、白粥与感冒也用于验证不同主题的原文并列。模型只有在原文支持时才能联系作答，证据不足应确认或说明记忆不足。

## 不做记忆融合

不把不同消息合并、摘要、改写成新记忆，不自动生成事实档案，不持久化推测的事件联系。允许一次提供多条原文，每条保留消息ID、轮次ID、角色、保存时间、截断标记。`memory_refs`还含排序分与检索路径；普通Android客户端兼容原有响应。

历史和引用是低信任资料。system明确区分user与assistant，JSON中的`<`转义，避免原文伪造参考区边界。文档引用也有同样的结构保护；不保证真实模型对自然语言指令完全免疫。

## 性格与持续会话

基础身份是诚实的AI恋人。应用preset一旦保存整份不可替换；custom的自定义偏好可编辑，不能切换成预设。`companion_profile=null`不强加应用性格，可在聊天中自行培养。三种预设是温柔体贴、俏皮亲昵、成熟稳重，支持AI女友、男友或恋人。

Android保持一个持续聊天页面。公司与模型绑定后退出或重新输入Key不解除本安装绑定；清数据或卸载会丢失本地Keystore信息，不能称跨设备永久身份。后台身份由公司与Key派生，换Key不会自动继承另一身份的历史。

## 验证与局限

权重对比：`backend/.venv/Scripts/python.exe scripts/eval_memory_weights.py --output scripts/memory-weight-evaluation.json`。六组权重使用同一组合成回归样本；默认与其他方案可能同分，不代表全局最优或真实模型回答正确率。

回归覆盖双方索引、长原文中尾、补建、删除一致性、事务回滚、身份隔离、配额、自然修订、原文边界和跨主题扩展。真实千轮与万轮结果见[长聊实测](LONG_CHAT_TEST.md)及[验证记录](VALIDATION.md)。

目前是词法聊天RAG，**没有聊天语义向量或Engram实现**。隐含指代、同义改写、单字主题、部分英文时间表达可能漏召回。附近候选及第三方排除是词法启发，可能带入背景噪声，不能直接认定为用户经历。超过配额的同等相关内容仍可能排除，节选可能缺上下文。FTS命中、SQL聚合与体积随历史增长，不宣称恒定耗时或无限准确记忆。

后续语义检索可沿用原消息ID及位置，无需记忆融合。见[Engram研究](ENGRAM_RESEARCH.md)与[存储说明](STORAGE.md)；原文与索引长期保存必然增加磁盘占用。
