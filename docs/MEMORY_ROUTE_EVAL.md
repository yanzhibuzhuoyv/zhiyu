# 旧事语义路由实验

2026-10-07。三轮研究中，固定BGE加监督意图分类头达到合成研究门槛：新保留题重要误跳0/24、日常正确跳过5/16，75条已知题回归也无重要误跳。该候选还未接入应用的自动跳过行为，下一阶段验证受控连续对话。

本轮只研究“这次回应是否需要查询更早的聊天原文”。现有后台记忆版本继续保存每轮双方完整原文，并按既有预算检索；记忆层级标注和意图路由是两项不同任务。[现有行为](MEMORY_ATTENTION.md)。

## 方法与边界

不增加同步云意图分类调用。复用本机已缓存的 `BAAI/bge-small-zh-v1.5`，CPU 两个计算线程、一个 interop 线程，512维，对当前输入与最多四条近期原话编码。原句 Q 必须独立满足跳过条件，加入近期原话后的 C 只能否决，不能把不确定的 Q 提升为跳过。未知、错误和实际 tokenizer 含特殊 token 超过512的完整输入均保留检索，不悄悄截掉句尾。

这里是对称分类任务，使用 `encode_documents`，没有加入文档检索 query 指令。BGE 官方区分短文本分类与短 query 检索的指令用法；其向量相似度不等于经过校准的意图概率。[模型官方说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)。本轮没有训练新的 encoder，也没有构建用户向量库或 Engram。

路由假定近期上下文仍正常提供，只控制更早聊天的查询；资料知识库仍按原 `use_rag` 行为处理。所有原文、后台识别和固定恋人设定保持现有契约。实验模块没有导入应用生命周期或聊天接口，不通过“门禁通过”自动激活。

## 首轮：最大相似度候选未通过

独立代理预先编写100条合成保守 gold：train50（present20 / retrieve30）、validation25（10 / 15）、test25（10 / 15）。train建原型，validation选择756组阈值，写入冻结策略文件后才编码test。选择阈值为 similarity0.60 / margin0.04，55个训练原型，原句与含上下文表示可能来自同一训练题。

| 检查 | 实际结果 |
| --- | --- |
| validation本应检索却跳过 | 0/15 |
| test本应检索却跳过 | **1/15** |
| test日常正确跳过 | 3/10，30% |
| test所有请求走跳过路径 | 4/25，16%，包含一条错误 |
| 热推理 p50 / p95 | 8.743 / 23.166 ms |
| 1,000个展示变体中的重要误跳 | 40/600，全部来自同一底题 |
| 门禁 | **失败** |

错误底题是合成的“我之前提到的那家修表店叫什么？现在想再去一趟。”近期上下文为空，旧店名存在事实缺口；模型却得到 present0.62534 / retrieve0.53727。主题与当前行动相似，不能证明旧事实已经足够。这是语义候选的实际误判，不是评分计算错误。

千次检查由25底题各40种空白、换行、标点和emoji展示变化组成，不是1,000条独立自然意图；不能把40个变体错误当作40个独立用户错误。冷加载46.44秒，权重文件95,827,648B；热推理仅是本机单进程识别耗时，不能称为Android端耗时、并发吞吐或完整聊天提速。

首轮证据目录为本机 `artifacts/memory-route-20261007-022731-8ec85c/`，含模型与四个源码SHA、冻结策略、保留集逐条结果及展示输入。策略SHA `aeae0d207b62634dfafa7289255d07ded7ec0e06e9097d98099dc257f474be31`。源码、模型和策略前后完全一致；源字节随后按已记录SHA核验保存到 `frozen-source/`。首轮验证集只保留汇总，不能从该目录独立重算全部真实校准分数；此限制在后续执行器中通过保存逐条分数与决定改进，没有覆盖原报告。

## 第二轮预先登记的候选

固定使用第三高 present 相似度 `p3` 与最高 retrieve 相似度 `r1` 比较：`p3 >= similarity` 且 `p3-r1 > margin` 才可能跳过。严格正差意味着全局最近三个训练原型都是 present；与 retrieve 同分即保留检索，训练排序不影响决定。每个train题只用原句Q的一条原型，避免同一题Q/C算作两份支持。仍保留Q独立、C只能否决及超长/异常回退。

这是保守近邻工程候选，不是三个独立事实证据，也不保证能识别否定、讽刺或历史依赖。官方最近邻说明提示边界同分和高维邻居的限制；后续监督线性分类头应作为新候选另行登记，不能用本轮test比较多个模型后挑较好结果。[官方最近邻说明](https://scikit-learn.org/stable/modules/neighbors.html)。

第二套独立200题先完整编写、冻结，再只用新的train100与validation50调整阈值；test50仅在新profile写入后首次评分。题库SHA `5a9c56d7e7f38ee92c293a327c605c2548bdd715b2072137849a52d9124de277`。第一轮失败题没有成为新增原型或阈值补丁。

真实结果：100个原型、756组阈值，validation最优日常跳过仍为0，按预定同分规则选择similarity0.95 / margin0.20。test的重要误跳0/30，但日常正确跳过 **0/20**；2,000个展示变体也全部检索，**门禁失败**。热p50 / p95为9.772 / 25.798ms，加载26.998秒。本轮只说明这一候选过于保守，没有达到优化目的。

另48次长度执行全部返回 `retrieve/input_limit`；实际覆盖8组不同输入组合（四种汉字长度×长Q/长C），不是48条独立自然长文。包含512、1,024、4,096和15,950汉字，均在16k单条接口限制内。tokenizer报告超512的警告来自长度检查；没有把这些输入送入encoder推理。

证据目录 `artifacts/memory-route-20261007-024224-69dfb1/`，策略SHA `b33defb9c44b4d0ff32e8b3cbc479ec00aaf0e0eea3da0723577b34ec2349654`。逐条验证分数/决定、源字节、模型和策略都已冻结；独审独立重算756候选和全部结果。与首轮题目、算法及阈值不同，不能称为同题对照或可靠性提升。

## 第三轮：监督意图分类头达到研究门槛

冻结BGE，仅训练轻量线性分类头，避免将“和哪个主题相近”直接等同于“是否缺少旧事实”。固定L2 LogisticRegression：C=1、l1_ratio=0、balanced、lbfgs、max_iter1000、tol0.0001、random_state0；没有比较多种训练参数后挑test较好结果。正类别明确为1=present。训练和推理都用单位向量，不收敛或部分训练输入不能编码时拒绝产出策略。[官方分类器参数](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)。

训练完整复用V2的100条train原句，旧validation/test不进入拟合或这轮调参。另一个代理先完成并冻结全新validation40 / test40，各16 present、24 retrieve。V3题库SHA `9525bae61b7b230029ded43fd52aabcdc80c4387ad648b625cb22b560b6addfa`，train规范JSON SHA与V2一致。三套共380条原创合成正文，380条唯一；新test与先前题库没有完全相同正文。由同一作者按固定准则写出的合成gold，不能当作独立同分布的真人样本。

只在新validation选择450组最近训练邻居距离下限与分类头阈值；最近邻仅作分布外否决，分类由头系数决定。sigmoid输出称 `present_affinity`，没有独立校准，**不是“61%准确”或正确概率**。[官方校准边界](https://scikit-learn.org/stable/modules/calibration.html)。写入完整JSON系数/截距、训练参数、类别映射、阈值和源码SHA后，才首次评分新test；依旧Q独立、C只能否决。

## 复现与判据

在项目根目录，用已有模型的实际本地目录运行：

```powershell
.\backend\.venv-route\Scripts\python.exe -m scripts.eval_memory_route --model <本地BGE模型目录>
.\backend\.venv-route\Scripts\python.exe -m scripts.eval_memory_route_v2 --model <本地BGE模型目录>
.\backend\.venv-route\Scripts\python.exe -m scripts.eval_memory_route_linear --model <本地BGE模型目录>
```

独立实验环境 `backend/.venv-route` 不影响普通后端依赖，模型读取设置为本地离线；依赖版本 sentence-transformers5.7.0、torch2.12.0、transformers5.10.2、numpy2.5.3、scikit-learn1.9.1，见 `scripts/requirements-memory-route.txt`。本轮Key读取0、云调用0，没有读取私人聊天库或改变原RAG文件。

预先登记门禁：validation和test重要误跳均为0、test日常正确跳过至少20%、热p95不超过100ms、展示扰动重要误跳为0。全部达到仅有资格进入进一步受控研究，不自动上线。脚本 `status=completed` 和退出0表示实验执行完成；语义候选是否合格单独看 `gate.passed`。

离线单元测试使用发明向量，检查拒判、上下文否决、长度、来源冻结、门禁和执行器契约；不能作为中文识别准确率。全部gold由独立代理编写，尚无真人标注、自然长期对话、并发模型资源或主观拟人程度评测。保存原文和减少等待的既有结果见[后台实测](MEMORY_ATTENTION_EVAL.md)，不能与这次不同范围的毫秒计时合并计算加速比。
