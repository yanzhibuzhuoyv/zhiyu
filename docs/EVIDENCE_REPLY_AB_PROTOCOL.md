# 单次来源约束回答：预注册协议 v1

本轮研究与生产隔离，使用全新合成题，不读取私人 RAG。保留全部独立原文，不融合、不覆盖、不删除。比较 A=词法优先、B=语义优先各自的自由回答 baseline 与来源分段 structured；每条只请求一次，失败保留，不追加审核或改写重试。既有失败不混进新题分母。

题目边界与题库测试由独立 Agent 预先编写；Agent 额度中断后，主代理接手合成具体文本。32 题，历史明确事实、日期/临时状态、作者/范围、当前/日常各 8。两题含超过 2500 汉字的真实语义长原文及尾部关键事实，长文叙事使用同一模板的变体，不当作独立长文分布。当前时间统一 2026-10-07T04:00:00+00:00，来源含时区。冻结完整题库、运行代码、协议、BGE 模型哈希和调用日程后才开始模型调用。金标、类别、审核说明不进入提示词。

普通实验 32×2×2=128 条，关闭思考；长输出补充选最长原文题，加其余类别首题共 4 题，4×2×2=16 条，开启思考并同加 1200–1800 汉字指令。两方法用相同生产人格、当前时间、近期原话、完整问题、来源、393216 最大输出 token、无整请求/读取截止。A/B 与方法先后交错，结果不会回写其他试验历史。模型 JSON 请求只对 structured 开启。

structured 契约：顶层仅 version=evidence-reply-v1 和 segments（1–32）。natural 原样自由文本，总量≤64000 字；source 仅 source_id、quote、scope=historical，quote 必须等于本次完整提供节选，作者/保存时间/截断状态由代码加入；uncertain 固定呈现“本次提供的记录还不足以确认。”模型不能填写角色、时间或已核实标签。严格校验重复字段、非有限值、未知类型/字段、虚构/重复来源、无时区日期；raw JSON≤2 Mi 字符、呈现≤128000 字。失败保留完整 raw 和错误，不呈现未经解析 JSON。合法结构只证明格式与逐字出处；natural 的无据事实仍可能漏出。

预先冻结判分项：完整 SSE/stop；结构可呈现；所需每条原文是否可用；全回答的作者、日期、暂时/现在、第三人/假设、缺席范围、无据机制/旧事；主问题回答正确性；有明确来源却退未知；日常回应自然度与多余引文；raw 首字、完整可呈现等待、输出长度、token。每条候选全部文本独立语义复查，复查不是产品请求。独立 AI 审查不是人工盲审，不称总体正确率或可靠保证。机器传输、结构通过与语义评分分别统计。

推广条件：先完成全部记录与独审、C/H 代码问题修复，再判断。发现自然段残留无据事实、未知误退、冗长引文或等待代价时保留失败，继续隔离，不自动切换生产。若 A/B 得到相同来源，模型输出随机差异不归因检索顺序。

DeepSeek 官方 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/) 要求请求 response_format=json_object 且提示明确 JSON，并指出可能空内容；[Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/) 列出 SSE、JSON 和输出 token 参数。本地仍做严格解析，不将 JSON 模式视为事实校验。
