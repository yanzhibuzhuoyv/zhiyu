# 手机本地记忆：语义标签与分层

本模块把旧后端的语义标注、层级和承诺保护搬到 Android。它不依赖电脑服务。向量编码与检索由 `LocalSemanticService` 负责；语义标签识别使用用户已绑定的 AI 公司和模型，通过现有固定官方 HTTPS 客户端调用。没有 Key 时只保留本地原文，不发出标签识别请求。

## 原文与标签

每一条用户/AI 原话仍是独立的压缩原文。标签只包含原消息 ID、作者、时间、完整原文 SHA、UTF16 起止、片段 SHA 和类型。不会生成摘要、融合记忆、改写原话或删除原话。API 的完整消息读取由 `LocalChatDatabase.recognitionOriginal` 提供，读取时检查全部原文的 SHA 和 UTF8 编码。

长消息按最多 16,000 UTF16 字符的连续窗口识别，持久化窗口结束游标；遇到代理对移动到完整字符边界。成功的空标签也完成该窗口，错误/取消不会推进。每次模型输出最多八条标签；这限制标签数量，不代表窗口所有事实都已准确分类，完整原文仍可从向量和精准索引找回。

JSON 入口拒绝递归重复字段、额外字段、错误类型、非有限数字、半个代理对、Markdown、深度/大小超限。置信度是模型自评，不能作为准确率；只有自评至少 0.85、作者对应且原话完全相符的标签才进入生命周期。语义模型仍可能分类错误，因此标签不能替代独立原文证据。

## 生命周期

- 普通或证据不足：中期 `mid`。
- 同一用户、同一聊天、同一类型/主题的愿望、偏好或习惯：至少三个独立 UTC 日、最早至最晚至少六天，成为长期 `long`。同源多片段、同日重复、AI 回声不能增加独立天数；愿望仍是愿望，不会变成永久爱好。
- 用户明确的固定资料/爱好或明确要求长期记住的原话：永久 `permanent`。生日不从发送时间猜日期，不擅自选农历/公历。
- 更正保留旧原话，以 `supersedes` 指针标记同作者/同主题的较早标签。固定资料更正可永久；临时愿望/事件的更正不自动永久，当前纠正证据受保护。
- 检索沿有界更正链补当前独立原文。链上继承的 score 表示从旧候选传播的查询相关性，不是新原话的实测向量余弦；它不能证明属性值。最终仍由完整 SHA 核验的原文、作者和时间提供证据。
- 待履行承诺保持中期并 `pinned`；日期过了仍不能当成兑现。完成/取消需明确原话，只在唯一对应的旧待履行承诺上解除其当前保护，多个同主题承诺存在时不批量解除。

人工层级优先。当前永久或受保护原话若在冷索引内，在同一个 SQLite 事务中恢复活跃索引。原文内容、ID、作者、时间和完整 SHA 均保留。没有自动批量降温；`canCool` 默认关闭。冷库检索由核心服务真实执行，检索失败不能断言用户从未说过。

## 后台与取消

`LocalMemoryRecognitionScheduler.schedule(context)` 安排唯一一次任务（15 秒起始延迟）和 15 分钟周期恢复任务，需联网。由主应用在成功登录/发送和转入后台时调用；清除 Key/注销时调用 `cancel(context)`。每次最多处理四个窗口，避免一次扫完整个原文库。

任务使用当前安全凭据和恋人绑定的快照。工作队列只存 provider/model，不存 Key。进入前台立即取消当前批次；Key/绑定改变每 250 毫秒检查并取消可中断 HTTPS。单次后台标签请求最多等待 60 秒，不改变用户聊天回答的等待策略。SQLite 写事务不跨模型等待、不使用前台聊天 Mutex。

开始/提交/提交末尾检查授权，job lease、owner/chat、作者/时间、原文 SHA 和 revision 均使用 CAS 检查；最终授权撤销会回滚标签、层级、索引恢复和游标。取消释放 lease 且不消耗错误重试次数；真正解析/模型错误最多三次。重启后超过三分钟的旧 running lease 可恢复小批处理。当前接口的授权检查与安全凭据清除仍是两个存储操作，不能声称实现了跨存储线性一致的撤销事务。

## 验证边界

新增 JVM 测试覆盖层级、严格 JSON、完整字符窗口、后台前台/Key 取消、晚结果、批量上限和重启游标；新增独立 UUID Android 数据库测试覆盖真实 SQLite CAS、最终授权撤销回滚、冷恢复、更正、长窗口重启、过期 lease 和越窗口拒绝。测试使用合成数据，不读正式聊天库或真实 Key。

2026-10-09 r8实际验证：本模块33项JVM全绿（包含在248项全量单元中），7项真实Android SQLite全绿（包含在67项同次原生回归中）。独立UUID云冒烟使用已授权固定官方模型分类两条合成生日原话，旧标签superseded、当前永久、链接1、重启原文SHA均通过。它属于 `NativeOfficialAiTest` 同一个JUnit的一部分：鉴权/聊天3次加分类2次，不能把两个指标包或模型调用数当独立测试数。真实报告和审查边界见 `artifacts/native-lifecycle-final-review.md`；两样本不证明普遍语义准确率。
