# 单次来源约束回答 A/B 实测

本轮完成 144 次官方 DeepSeek Flash 调用：128 条普通回答关闭思考，16 条长回答开启思考。来源分段方案能由代码标明原话作者和保存时间，但出现 6 次空白输出，且增加完整等待与档案口吻。**当前保持研究隔离，未接入默认聊天或 Android。**

## 实验边界

预注册见 [协议](EVIDENCE_REPLY_AB_PROTOCOL.md)。新合成题 32 道、4 类各 8，192 条独立原文；不读私人 RAG。当前时间统一为北京时间 2026-10-07 12:00，来源都有 +08 时区。两条长原文分别 3280/3429 字符，3002/3153 汉字，答案在尾部；长文共用叙事模板变体，只证明尾部检索能力，不能当独立长对话分布。

A=词法先查、语义补漏，B=语义先查、词法补漏。每种顺序分别对比 baseline 自由回答与 structured 单次 JSON 来源分段回答。问题、原文、人格、近期聊天、时间、思考和输出预算配对一致，先后交错，生成答案不回写其他试验。使用实际 BGE-small-zh-v1.5 窗口向量，合成范围含 16 轮噪声；全部 19 道声明所需来源的题均召回，不能把这个小候选库的结果外推到万轮生产索引。

structured 保留自然段；来源段逐字复制完整提供节选，作者、保存时间、截断状态由代码加入；未知段只说明本次记录不足以确认。合法结构不会证明自然段的事实正确。提供节选仍可能缺前后文，保存时间不是事件时间。不融合、改写或删除原话。

候选同时改变结构指令、JSON API 模式和来源呈现，且在生产 system 原有记忆之外再提供一份来源数据；只能对比整体方案，不能把效果单独归因模板。36 组四条件的来源全相同，72 组同顺序的方法配对历史 SHA/问题/思考一致。A/B 的模型随机输出差异不证明检索顺序优劣。

## 可交付与等待

每条只调用一次，不追加审核、改写或重试。max_tokens=393216，读取/整请求无截止；所有 144 次都以 HTTP200、stop、DONE 完整结束。baseline 72/72 非空；structured 66/72 非空并通过严格解析。剩余 6 条是纯空格，全部发生在普通日常题，A/B 各 3。原始空格和失败均保留，未凑重试到通过。

普通回答含检索、生成、解析的完整等待：

| 顺序 | 自由回答可交付 | 来源分段可交付 | 自由回答中位 / P95 | 来源分段中位 / P95 |
|---|---:|---:|---:|---:|
| A | 32/32 | 29/32 | 1.081 / 1.507 秒 | 1.372 / 1.887 秒 |
| B | 32/32 | 29/32 | 1.101 / 1.686 秒 | 1.294 / 1.849 秒 |

这比上一轮逐句再审核少了一次请求，但对照题不同，不能声称跨实验的同题加速比例。JSON 的首个上游字符通常只是结构开头；当前研究呈现须等完整解析，不能把约 0.75 秒的上游首字当用户可读首字。

长回答每格 4 条均完整可交付，中位等待：A 自由 9.986 秒、分段 19.264 秒；B 自由 15.425 秒、分段 14.298 秒。仅 4 个配对样本且来源相同，不选顺序赢家。要求 1200–1800 汉字，实际呈现达标自由 A1/4、B2/4，分段 A1/4、B0/4；分段字数包含复制引文。模型自行 stop，不是 token 用完或本地截断。

DeepSeek [JSON Output 官方说明](https://api-docs.deepseek.com/guides/json_mode/) 提醒可能出现空内容；本轮确实观察到 JSON 模式的空白返回。未证明具体服务器内部原因，不能归因 Docker 故障。R1 旧运行器将它标为 transport_incomplete；结果原件不改。实验结束后用真实红灯回归将新运行器细分为 upstream_empty_content，保留原 SSE 完整信息。

## 独立全文审查

三个专业 Agent 分别审前 64 条普通、后 64 条普通、16 条长回答，所有自然段和来源段一起检查。审查是独立 AI、标签可见、非人工、非用户研究；不是可靠性保证，也不报泛化准确率。主问题正确和整句话无附带错误分别记录，空白属于未交付。

普通 32 题每格的独审结果如下；“无标注错误”只表示这位 AI 审查员未标作者/时间/范围/无据旧事错误，排除未交付，不是实际正确率：

关键失败：普通 index37 已提供凌晨原文和时间，却说“你在这里没提过‘凌晨消息’”；分段自然文字也曾虚构今天没泡茶、推断窗台光照、把当前问题改成今晚、把忙“一阵”扩大成“一天”。旧承诺的来源可用却有“记录里只有你问”的范围措辞。四条长字段题完整复读了约 213/385 字符的节选，答案值正确但引文远超所需。保留实际文字和审查解释；不能用模板的正确作者遮盖自然段的问题。

16 条长输出的主问题全部正确，包括尾部暗号、历史日期、未确认礼物和当下分享；全文另有 10 条被标附带范围/时间/旧事问题，自由/分段各 5 条。有的虚拟 AI 自述涉及人格解释歧义，报告保留具体原句，不把 AI 标注当客观事实。明确的例子仍包括“你没跟我讲过”、无依据的长期习惯以及“一阵”扩成“一整天”。

date-07 是预约日期已知、是否赴约未知的混合题，unknown_current=false 不能推出已完成。相对日期按合成题约定的 +08 发言保存锚点计算；真实导入的保存时间可能不是发言时刻，仍需真实时间锚。审查结果与确切错误原句见 artifacts/evidence-reply-review-humanlike-part1.json/.md、part2.json/.md 及 evidence-reply-review-long.json/.md。合并统计 evidence-reply-review-combined.json 验证 144 行无缺失/重复、每条 issue 均为答案真实连续子串，源结果 SHA 不变。

这轮不采用分段方案作为默认聊天：它只收紧逐字出处，未约束全部自然段，还增加空白失败和台账感。下一研究应验证选择性复核的触发质量，让有风险的追忆/矛盾/时间换算得到额外核对；日常分享继续自然回应。不能按几句关键词判语义安全，也不能把下一步描述成已完成的产品行为。
