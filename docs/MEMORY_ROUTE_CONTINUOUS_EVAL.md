## 类系统提示词：事实约束与性格分开

后端基础系统提示新增内部证据状态：实际提供的近期消息数、较早来源数、检索是否结束，以及“未命中不证明从未说过”“AI说法不证明用户事实”“问句不证明事实”“缺少来源不证明事件没发生”。它与可选恋人性格设定一起发送；用户性格预设的锁定规则不变。

对“你以前说过吗／做过吗”的回答遵循通用规则：

- 找不到对应用户陈述时，先说明“目前可用的记录无法确认”，不能任选答案或把未知回答成否定。
- 用户问句、候选、假设、虚构和第三人转述不等于用户确认；旧AI猜测也不是用户证据。
- 用户明确否定可按原话回答，AI自身明确承诺可按AI原话核对。
- “当时未决定”只证明当时状态，不能断言后来仍未决定。检索完成只表示查询结束。

没有新增前置云分类、关键词名单或改写历史。新增5项后端契约测试检查实际来源计数、历史预算、低信任标记及原话保留；这些检查不能证明模型必然服从。

另一个作者在看到真实答案前冻结24条新合成题（16未知、8已知），加3条明确标记的已知回归。每题独立原文＋22桥接轮，后台识别关闭以隔离聊天证据；每次27完整回答＋1鉴权，共28调用。R1新题首次测过后，R2只能算同题回归，不再是新保留集。两轮都保持输入/gold不变，没有用题目重新训练路由。
