日期：2026-10-11，Asia/Shanghai。0.2.2 / code8 已完成本轮原生验收并交付同签名 ARM64 试用包。功能和仍未完成的边界分别记录；不把试用版描述为商业发行。

## 手机里的功能

选择公司并输入自己的 API Key 后，手机直连官方 HTTPS；公司目录、原文、语义索引、OC、图库、日历和离线声音均在设备上。没有电脑地址输入，不需要 USB 映射或电脑后端。云端聊天、生图和独立识图仍需要网络及有效 Key，Agnes 凭据与聊天 Key 独立加密保存。

共享 `shared/companion-contract.json` 生成两侧14条有 ID 和适用范围的规则。`ok / not_searched / partial` 区分执行完、未执行和不完整；事实状态不混入行为指令，三态下空来源均不证明“你没告诉过我”。Kotlin 是产品实现，Python 冻结为 legacy；没有声称两套 schema、FTS 或排序等价。规则仍不能保证每次模型回答都合乎要求。

手机继续保存双方每条独立原话、作者、时间、ID 和 SHA；语义优先、精确补查、三层标签及可逆冷索引保持，不融合原话。照片的空文字原文保留为空，派生任务标记 no_text，不制造向量或付费文字事实。OCR/视觉观察是低信任辅助材料，不作为用户亲口说的生日或约定。

水彩页面、镂空气泡、头像背景、字号、秒级时间、长间隔分隔、键盘可见与旧消息位置已接入；等待只显示“对方正在输入中”。前置申请通知、粗略定位和日历权限，性格决定主动频率；恋人日记和明确约定静默写入自己的日历。年度生日重复、提前提醒、取消改期均只操作本 App 创建的事项，以同子句原句、原日期、活动及 Provider revision/CAS 限制动作。

绑定时立即产生当日轨迹，换日及恢复补偿；每时段8个选项组合。表情内置20张CC0白猫，可在普通回复里按性格选择。OC支持真人原图、抠图及保留/去除笔刷，非真人2D部件或真实GLES3D参数制作。单翼、多翼和武器可手工保留；自动分割不能保证识别每种附件。自研局部网格做眼口和身体参数动画，并接轮流角色通话；没有冒称完整自动Cubism拆层补画绑骨。

两次描述生成由持久任务账本控制；成功重放不再发请求，未知收费结果不自动重试。生活图预先准备：Agnes只生成背景，经独立检查后手机合成已确认的主体原图、部件或几何；拒绝或无Key用本机场景，聊天不等待产图。日期、时段、角色版本和身份SHA共同限制输出。背景检查是可出错模型，不能保证百分之百视觉一致。只回收超过7天且未发出的派生缓存，全历史消息引用、共享SHA、OC原图、聊天图片与内置素材受保护；保护元数据损坏则停止回收。

用户可发照片；已核验的多模态模型接图，文本模型用离线中文OCR或独立Agnes识图，近期追问可携带最近一张照片/观察。相同照片有意重新选择会产生新附件ID，原图blob仍按SHA共享。已发送与草稿清理失败分开，重启按精确ID检查完整历史，避免误重发。ASR/TTS和三声音随包，无需再次下载；识别文字可改后再发，按需申请麦克风权限，退出/后台取消并释放资源。

## 从失败到修复

终审发现日历可能借用别的子句取消活动，新增真实16项/4失败后，改为原日期/完整活动/取消谓词同子句，拒绝照常/保留反证和电影节等子串；46项日历纯逻辑及Provider回归通过。OC旧pending被新外观超越原来会卡住，现凭新鲜版本先保留审计再归档，活跃发布不能被归档、审计失败仍可恢复；取消尚未交接的Bitmap确实回收。新增7项恢复和2项ownership原生通过。

背景相同SHA并发和否决曾重复收费；真实4项RED后加原子checking/approved/rejected/unknown收据，拒绝/异常/中断不自动再收费，6项原生回归通过。照片已成功但草稿清理异常曾显示发送失败；现在先合入成功消息，清理单独处理。恢复测试另发现相同照片重选复用ID，真实2项失败后改为新metadataID/共享blob，3项原生通过。缓存过期后的新附件引用和慢回复附件竞态也已修，不影响成功文字或删除原话。

语音曾有 JNI typed invoke 查找崩溃，命名回调提供 `invoke(float[]): Integer` 并保留R8规则，实际取消后再次合成通过。随后随机合成使同句十轮准确度波动：旧r13 9/10关键词但平均CER36.67%超35%；新增稳定性取得真实RED后显式关闭VITS两个噪声项。r15波形和时长已稳定，但第三声2读成“您好今天的天星戏真好”，只7/10关键词，仍失败。

零噪声候选0/1/2各三次短句，CER分别11.11%/33.33%/33.33%；另三句日常对话各三次，均值13.535%/22.626%/38.182%。依据独立句诊断改第三声为0；历史99/2都持久迁移到第三声0，10/33与未知值拒绝保持。迁移先取得8项单元/3失败RED，最终422单元GREEN；r16三声各三次稳定性及正式十轮GREEN。正式8/10、平均CER≤35%及每声线有关键词的断言不变，实际10/10、10%。同句合成回识别不是自然用户、方言或噪声准确率；关闭随机韵律后的自然度仍需试听。

三个专业终审及后续修复记录在 `artifacts/native-v4-retrieval-calendar-final-review.md`、`native-v4-oc-stock-retention-final-review.md`、`native-v4-media-voice-background-final-review.md`；最后声音替换另见 `native-v4-voice-final-review-r2.md`。已核对范围没有未关闭CRITICAL/HIGH；不将局部审查当作全项目安全认证。
