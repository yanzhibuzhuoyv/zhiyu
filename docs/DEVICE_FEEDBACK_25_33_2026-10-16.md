## 连续输入与动作的一致性

用户每句原文、每个稳定 request ID、次序指纹和成员映射在一个 SQLite 外层事务落地；UI 回调开始前整组已经持久化。取消发生在中途时，原文、全文索引、成员映射与 updatedAt 一起回滚。已经提交但没等到回答的组不会再请求模型，完整 pair 只重放原 pair。拒绝单独重发旧成员时，也不得执行其中旧的“恢复主动联系”。

这轮真实审查复现了旧 batch/单条回放撤销后来 PAUSE 的问题；现将 queued 联系命令放在发送锁内，只允许首次提交执行。新暂停状态和修订不被旧重试改掉。

“发自拍”后补“在家那种/对了穿红裙”仍组合理解；“不用发了/算了/换个话题”之后只执行后续动作。边界即使在同一条原文中也生效。只裁临时动作输入，提供给模型和存入 RAG 的原文仍完整。

混合照片请求与另一个问题时，待备提示或借图固定说明不能覆盖整轮回答；同一条消息里的复合请求也如此。只有严格匹配整句纯索图才保留快捷待备回复。没有图库时仍回答别的问题；借图最后核验成功才带图保留正文。若 OC、轨迹或候选在期间变化，保守退回无图；无图却明确自述已发送时只作有限的反事实保护，不宣称通用语义校验。

## 使用限制

本轮没有真实手机、物理麦克风或新付费生图。识别测试包括真实内置 ASR/TTS 和延迟模型准备下的完整 PCM，但不代表自然人噪声录音准确率。语音的音高变化与情绪表达仍受现有模型限制。

照片需要已配置图像服务和实际像素审核能力。DeepSeek Flash 的已有原生视觉路径保留；未验证的纯文字模型不能伪装成审图模型，应用会单独说明能力不足并在新收费前停止。生图 Key 本身不能证明图已成功生成。公开模型目录只发现三种图像模型，本轮没有捏造额外视觉聊天接口或把聊天公司的 Key 转发给中转站。

角色识图、人物一致性、红米后台通知到达、真实通话回声与时延仍需要手机体验验证；此次自动测试不会被写成这些体验全部通过。
