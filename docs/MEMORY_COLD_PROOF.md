## 实际回查边界

第9,000轮双方中部/尾部四个词项探针在普通上下文中找到相应原文，字符区间逐项核对；扫描仍报告`complete=false`，不伪称整库已查完。耗时约0.206–0.494秒，包含原文查找但没有云模型回答。

第1轮用户中部及第250轮AI尾部两项早期探针，首次有界上下文没有找到；经显式续查三页后找到并最终`complete=true`，共解码40/34条原消息、总约0.587/0.602秒。每次扫描有上限，页间会有边界重叠，报告的累计20,002目录扫描不是20,002条不同原文。恢复两条活跃消息后和只读打开整理副本后，六个探针均再次通过。

整体398.387秒包含全库校验、编码、冷目录生成、重建、回查和整理，不是聊天延迟。候选是词项FTS/Bloom，没有证明任意同义句向量召回、自然语言分类准确率或模型利用记忆回答正确率。
