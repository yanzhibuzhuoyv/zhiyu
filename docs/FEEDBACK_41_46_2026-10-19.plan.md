# 0.2.16 反馈 41–46 修复计划

基线 e08b1b6 / 0.2.15。保留原文、音频、OC、原背景与绑定；旧 backend 工作区、长测及回执不修改。

1. 时间：校验系统网络时钟与用户可见设备时钟的偏差；覆盖普通聊天中的错误当前报时，保护故事、引用和其他时区。不能只测独立“几点”。
2. 语音输入：保留音频和转写，只向当前语音轮提供真实 ASR 来源和保守谐音理解规则；不声称模型收到未传送的音频，不猜专名、数字和否定意愿。
3. 已确认自像：确认归属持久化并绑定当前 OC；同一整图无损重新编码仍认，陌生图片不冒认。纯身份询问可由可信归属直接答，复合问题保留模型路径。
4. Live2D：用户确认“重框后画面正常但不动”。按当前可见遮罩重建局部运动场，验证凹形与孔洞、强度、保存重开及 GPU 像素；不移动整个背景。
5. 语音输出：保留用户音色与基准音高，增加有限、确定性的语调和能量起伏，导出真实 WAV A/B；不宣称真人情感语音。
6. 天气：前台持续使用也刷新；明确询问天气且缓存缺失时在已授权前台尝试获取。失效/撤权/定位失败有真实状态，不捏造天气，不强行后台定位。

root 统一运行 RED/GREEN、构建、lint 和原生测试；三个专业代理分别语音、归属、Live2D，非 DSH。验收后同证书 0.2.16/code22 APK、报告、白名单提交及更新交接。当前无手机，模拟器结果不外推为新实机通过。
