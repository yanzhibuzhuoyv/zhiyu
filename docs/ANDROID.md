# 知语 0.2.2 手机独立版

原生 Kotlin + Jetpack Compose，应用 ID `com.zhiyu.app`，Android 8.0 / API 26 及以上。文字聊天、原话记忆、资料和图片均由手机管理；模型请求直接通过 HTTPS 发给用户选择的 AI 公司。手机仍需互联网和有权限、余额的 API Key，电脑、Docker、USB 映射不参与使用。

## 安装与绑定

本轮版本为 0.2.2，versionCode 8；最终测试与安装包证据见 [v4 验证记录](NATIVE_V4_VALIDATION_2026-10-11.md)。覆盖安装应沿用原签名；卸载或清除应用数据会丢失本地聊天、绑定及文件，不是升级步骤。当前不是应用商店正式签名或收费更新发行包。

0.2.2 新增真实手机 Agnes 客户端、独立图像 Key／持久额度、固定 OC 后台库存与缓存回收、照片发图和追问、2D／3D 编辑、局部眼口动画、三声音离线轮流通话、年度生日和约定取消／改期。共享规则与三态已接入，Python 冻结为 legacy。完整能力和剩余边界见 [功能对照](MOBILE_FEATURE_PARITY.md)；下文保留旧版实现说明，以最新对照和 v4 验证为准。

公司列表随安装包提供，普通页面只有公司、Key、可选模型和恋人设定。真实短请求验证成功后固定公司与模型；固定预设继续只读，自行调教仍可调整。同一安装内更换有效 Key 不重置本机聊天，也不能换 AI 公司。未配置 API 代理，不跟随 HTTP 重定向。

Key 与绑定沿用 Android Keystore / AES-GCM 加密，不写入日志、数据库或素材。退出只清除 Key，保留固定关系与本机数据。启动读取历史无需先连电脑服务；实际云请求失败时保留原话和绑定，显示服务商的网络、授权或配额错误。

### 从旧版升级

沿用原 Key、公司、模型及恋人设定；旧电脑地址仅变为内部本地模式标记，不访问该标记域名。旧版完整历史和 OC 资产主要在电脑数据库，覆盖 APK 不会自动把它们变成手机数据。新版会提示旧历史尚未转入，旧数据卷仍保留；目前尚无可用的完整迁移工具。不能把新本地空历史说成用户从未讲过。

## 手机数据与回复

- 一个持续聊天页面，无新话题、会话列表或用户记忆管理入口。
- 回复中仅显示“对方正在输入中”；每条已保存消息显示秒级时间，跨天或间隔五分钟另有居中日期。字号14–26sp与系统字体缩放叠加；键盘弹出时跟随聊天尾部，手动阅读旧消息时保持位置。
- 用户和 AI 每条完整原文分别保存，保留消息 ID、作者、时间；无损压缩及 SHA 校验，不以融合摘要替代正文。历史按最多 100 条分页。
- 本机 BGE INT8 产生真实 512 维向量，先查语义关联，不足时补中文词项和 FTS。索引可分批恢复，活跃和冷原文均可查；候选提供独立原文节选、作者、时间、消息 ID 和范围，不融合。最终原文预算为 12,000 UTF16 字符，完整存档不受这个提示预算限制。实现与测试状态见 [本机语义编码器](LOCAL_SEMANTIC_ENCODER.md)。
- 后台由已绑定的公司和模型识别原文标签，再按明确资料、跨日重复和待履行承诺调整中／长／永久层级。更正通过原文指针连接，保存旧原话；进入前台或 Key 改变取消后台识别。自动批量冷却默认关闭。标签和评分可能出错，不能替代原文证据。见 [生命周期规则](NATIVE_MEMORY_LIFECYCLE.md)。
- 类系统提示要求自然表达；无充分记忆时表达自己没印象，不能从“没有召回”断言用户从未讲过。模型输出仍可能违反提示，真实小样本不能保证所有情况。
- TXT / MD / PDF / DOCX 由本机解析，文件上限 5 MiB。拒绝 DOCX DTD、过量展开、加密或无可提取文本的 PDF；扫描文件需另做 OCR。
- 可修改两个头像和背景；本机独立图库、表情包目录与导入选项。配图在同一次模型回答内选择，无额外图片分类或实时生图等待。当前内置 2 张虚构猫/风景图、20 张 CC0 白猫表情；授权未确认的第三方 QQ 图没有打入可分发安装包。

## OC 图片和动态角色

原图保存在手机，内置 U2NetP 做本地前景预览；透明原图保留 alpha，杂乱背景可以手动保留或去除区域，再确认采用。任意翼数、武器等不会被限定成固定模板，但自动模型不能保证全部正确，确认前应检查部件。

该前景资产是后续**各用户自己的 OC 动态模型**的输入。完整 Live2D 还需要原图拆层、遮挡补画、网格和动作绑定；本版没有自动生成完整 Cubism 模型或视频通话。描述生成中转站尚未配置，失败不会扣除两次生成机会。研究及实现边界见 [NATIVE_CALL_REFERENCES.md](NATIVE_CALL_REFERENCES.md) 与 [OC_PORTRAIT_AND_CALLS.md](OC_PORTRAIT_AND_CALLS.md)。

## 主动联系、天气和日历

进入已绑定聊天后顺序申请通知、粗略定位和日历权限；拒绝不妨碍聊天，拒绝或撤权后不循环弹框。旧“主动联系”开关已移出设置，系统授权决定启用状态。WorkManager 在设备允许的后台条件下执行，不保证手机厂商每次准时唤醒。焦虑型未回复逐步缩短间隔，疏离型一次或不发；不再限制夜间时段，保留性格每日限额、近期互动保护和请求幂等。锁屏公开通知隐藏聊天正文。

定位获准后启用天气关心；不申请后台定位、不保存原始坐标，过期或撤权天气不再提供给模型。日历获准后，恋人可在同一次自然回复中附带隐含动作，记下自己的当日日记、明确生日/纪念日及已确定约定，无需用户说“写进日历”或逐项确认；界面不弹成功通知，聊天不讨论内部记录。仅操作知语专用本地日历，不读取其他日程。日期与原句有保守证据校验，未确定的假设、候选与询问仍保留在聊天原文中，不能被当成确定安排。用户仍可通过“日历”菜单自行写日志。[权限与数据流](CARE_FEATURES.md)

首次成功 Key 登录就建立当天持久轨迹，重启和更改外观不重写已保存活动；后续尝试北京零点刷新，前台一分钟巡检及后台补偿处理延期。当前轨迹来自四组本地模板，尚不是自由语义生成、图片预生成或真实用户定位轨迹，详见 [日轨迹状态](DAILY_TRAJECTORY_NATIVE.md)。

## 构建

使用 JDK 17+、Android SDK 36 和项目 Gradle Wrapper。人物模型、语义模型和种子素材需准备到项目忽略目录，构建校验模型 SHA 后打包；运行时不下载模型。语义模型准备方式及固定来源见 [编码器说明](LOCAL_SEMANTIC_ENCODER.md)。

```powershell
cd backend
uv run python prepare_portrait_model.py --output ../artifacts/portrait-models/u2netp.onnx
cd ..
python scripts/prepare_native_media.py
cd android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
```

`prepare_native_media.py` 使用本机已有、SHA 核验的 CC0 原图和先前生成的两张照片。新 checkout 尚需取得这些来源素材；该步骤不会从未授权第三方图库抓图。构建文件允许 `-PzhiyuPortraitModel=绝对路径` 指定相同 SHA 的模型。

电脑后端代码与旧测试保留，供开发和研究使用，其说明位于 [ANDROID_BACKEND_LEGACY.md](ANDROID_BACKEND_LEGACY.md)。本地版本的实际测试结果另见当前交接与本轮验证报告，不沿用旧真机结果证明本版已通过。
