# 摄像头审查与宣传片计划 · 2026-10-20

用户顺序：先多智能体审查新增摄像头，问题闭环后使用 Remotion 制作项目宣传片。

## 验收顺序

1. 以 `a0b09c8` 为起点审查摄像头权限、可见生命周期、镜头换代、图像编码、请求取消和数据去向。
2. Codex 统一运行 JVM 与专用模拟器回归。DSH 实现限定修复，独立 Agent 审查与补测试；代理汇报不作为测试通过证据。
3. 修复确认的问题，再做代码复审。模拟器结论不外推真实镜头、弱光、热负载或云模型识别准确率。
4. 用 Remotion 输出可播放 MP4 和可重渲染源码，检查关键帧、文本可读性、画面与声音时长。

## 宣传片方向

- 延续产品奶油纸色、水彩花卉、鼠尾草绿与暗玫瑰红，表现长期 OC 陪伴与日常分享。
- 用合成示例对话演绎聊天、原话回忆、日常照片和授权摄像头单帧观察；明确示例演绎，不导出真实私人聊天或用户镜头。
- 不承诺永不遗忘、绝对人物一致、完全离线聊天、持续视频理解、零延迟或系统无条件后台到达。
- 宣传源码独立放在 `promo/`，不增加 App 的 Node 运行依赖。视频与审查日志放在忽略的 artifacts，最终交付桌面易找位置。
- 使用已有水彩背景、AI 生成的示例生活场景与本轮原创音轨，记录素材来源；无自动发布或 GitHub push。
