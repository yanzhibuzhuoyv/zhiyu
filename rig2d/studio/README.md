# 本地角色工坊

双击项目根目录 `启动角色工坊.cmd`，打开 http://127.0.0.1:8808/。全部图片、素材包和标注在本机处理，不需要 API Key。启动器仅使用已有项目 `.venv`，不会自动下载依赖或分割模型。

1. 导入照片、插画或线稿。最长边超过 1536 的图片会等比缩小，EXIF 方向会处理；原上传文件另外只读保存。
2. 初次导入保持原始姿态。建议眼口可能误检，请分别选择左眼、右眼、嘴巴并拖出真实范围，再点击头部中心和颈部支点。
3. 在“头发与附件”中点选轮廓或画保留，可独立标注武器、飘带、翅膀和碎发。整体保留范围需自己确认，未确认区域不会被自动裁掉。
4. 改错可用“撤销修改／重做修改”（Ctrl+Z／Ctrl+Shift+Z／Ctrl+Y）；“查看原图”可随时对照，返回编辑后修改保留。删除附件也可撤销。
5. 先完成整体轮廓，再保存更新预览。保存时编辑锁定，失败后修改仍保留。调整转头、眨眼、呼吸等滑杆，或选择本地音频驱动口型；支持暂停、原始姿态、网格检查。
6. 保存后下载 `.rig2d.zip` 角色包，之后可打开继续编辑。角色包包含原工作图、标注、网格和纹理，不含原上传文件的 EXIF。撤销历史只保留在本次会话，新项目／刷新后清空，已保存标注保留。

按用户选择，自动结果是建议，允许人工修正后完成角色。不会把模型不确定的结果当作正确身份。撤销历史最多40步／32MiB目标载荷，活动画布和原图内存另外计算。当前电脑工坊验证见[修正报告](../docs/MANUAL_CORRECTION_2026-10-14.md)。

这是自研前视角网格动态角色格式，可用的小幅 2D 动画编辑器。不是 Cubism `.moc3`，不生成真实侧脸或背面，也没有把真实全双工通话接到手机。闭眼和口型由原眼口区域形变，未能自动补出原图看不到的眼皮、口腔或遮挡后的脸部；原图身份与分层质量仍需人工复查。

人物抠图的 SAM2 候选仍属于研究工具，不在默认导入中自动采用。浅色头发、线稿断线、同色背景、复杂武器及手遮脸可能失败。可以用保留画笔修正，不应把模型的 mask quality 当像素准确率。

手动建立环境时：`python -m venv .venv`，使用 `.venv/Scripts/python.exe -m pip install -r studio/requirements.txt`。启动命令是 `.venv/Scripts/python.exe -m studio.server --port 8808`，仅监听本机。依赖安装需要网络；当前电脑已经准备好环境。

用户提供的图片仅作为本地测试输入，不作为可再分发的内置素材。公开示例为项目自制十二翼合成图。性能报告指电脑测试，不能推断手机速度。
