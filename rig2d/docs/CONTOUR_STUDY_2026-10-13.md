# 轮廓拟合与完整工作图保留复核

本轮继续独立 rig2d，使用两张原有合成夹具，不读取用户图片、模型或 Key，不改知语 Android。结论是：**单一 Lp 代理能改善洞率，但这次候选漏掉发顶和边缘，不能采用为默认人物方案。** 原图、原参数、所有旧回执和门槛保留。

## 先定位原因

默认彩图正面洞率为 7.6946%，超过原 2% 硬阈值。新的独立诊断发现 5,802 个洞全部落在源图背景，0 个落在人物、0 个落在图外：代理轮廓和内容轮廓不匹配，而不是人物纹理未投影。`artifacts/front-diagnosis-2026-10-13-r1/front-hole-diagnosis.json` 保留实测。

## 有界研究与真实投影

`tools/fit_proxy_contour.py` 在至多 256×256 的布尔 ROI 上评估固定 648 个候选，图外扩张也计作背景。只使用 128 像素边长的合成诊断副本，研究条件为前景保留至少 95%、几何覆盖背景至多 2%；这不是身份或发布门禁。

| 候选指数 / rx / ry / cx / cy | 2.5 / .5 / .48 / 0 / .04 | 1.5 / .5 / .5 / 0 / -.04 |

彩图候选按原 inclusive box 映射为人工诊断参数 `--head-box 207,166.22,561,632.74 --proxy-exponent 2.5`：中心 384.5,399.98，半径 177.5,233.76 像素。没有变更生产自动定位或默认指数 4。

实际执行完整 384 分辨率、96 网格、512 纹理、2 倍采样、2 膨胀投影，耗时 320.51 秒：正面 baseline 232/71,568＝**0.3242%**，B 后正面 0%，B 后 ±45° 最坏 6.5517%，±90° 最坏 44.0848%。9 项硬自检与像素来源通过，原探针给出 `GATE_PASS_C_VIABLE`，但它仅回答该**人工候选的几何研究**问题，不验证人物保留、画质或真实照片。图册仍为 A 阶段，不能冒称 B 图像。

另一次独立正面诊断的 232 个洞中，222 个落背景、10 个落人物；源头并非全部背景，不能沿用默认诊断的「0 人物洞」结论。

## 完整工作图否决候选

新增 `tools/measure_contour_retention.py` 使用原始工作图像素中心，不缩略，不把新候选框作为分母。头框外的前景另列；所有结果固定 `identity_validated=false`。边界外几何会报错，避免截掉形状后制造高分。

| 固定原 ROI 的完整工作图 | 彩图 | 线稿 |
|---|---:|---:|
| 原 ROI 前景像素 | 145,987 | 155,244 |
| 候选漏掉前景 | **7,345** | **9,597** |
| 候选实际前景保留 | **94.9687%** | **93.8181%** |
| 头部完整保留 | 否 | 否 |
| 原框外前景 | 236,910 | 0 |

彩图完整工作图实际结果低于 95%，与缩略诊断不同。缺口变小是以漏掉发顶和边缘为代价，不能以几何通过覆盖这个问题。`geometry_background_ratio` 此处使用全工作图 alpha，彩图为 0.4803%；缩略评分将原 ROI 外全部当背景，两者分母/掩码不同，不能混用。

回执：`artifacts/contour-retention-2026-10-13-r1/retention.json`。配套 PNG 中，洋红＝原头框内被候选漏掉的前景，蓝色＝原头框外前景（不是背景，也不是已完成头部审查），橙色＝代理下的背景。原 RGB 和 alpha 没有被改写，PNG 只是诊断覆盖图。
